# MySchool

A modern, responsive school website built with React, TypeScript and Vite.

## Included
- Responsive navigation and layout
- Home, About, Academics, Faculty, Admissions, Notices, Events, Gallery and Contact pages
- React Router navigation
- Mobile-first responsive styling
- Accessible semantic HTML and simple reusable page structure

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The site is currently content-driven on the frontend and ready for a future ASP.NET Core Web API integration for admissions, notices, events, gallery and administration.
